# V4 Release Notes

## Added

- Plinko and configurable poker tournaments.
- A unified Casino Designer with live editing, complete design presets, asset controls, revision history, preview, and publishing.
- VBP partnerships, streamer referrals, sponsored plans, hosting credit transfers, and partner revenue tracking.
- Updated registration and sign-in experiences with Kick and email account support.
- Dedicated leaderboards, expanded casino community features, and improved rain presentation and controls.

## Changed

- Casino navigation and game routes are simpler, with compatibility redirects retained for older links.
- Trial billing can schedule a future paid plan or activate it immediately without losing eligible trial benefits.
- Branding, layouts, artwork, icons, sounds, and responsive game presentation have been expanded.
- Production startup, database migration, and container deployment now use a consistent persistent SQLite setup.

## Fixed

- Strengthened account, session, tenant, upload, and outbound integration safeguards.
- Improved game settlement, retry safety, capacity handling, and billing consistency.
- Corrected clean-install database setup and production container startup.
- Updated automated coverage for V4 capacity and integration behavior.

## Removed

- Originals and Live Bets are no longer separate sidebar destinations; bet history remains available from the lobby.
- Duplicate legacy editing screens were retired in favor of the unified Designer, with old links redirected.
